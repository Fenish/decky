## Development startup fix

Electron 44.3.0 has no postinstall lifecycle hook and downloads its executable on demand through its package entry point. electron-vite 5 reads Electron's `path.txt` directly instead, resulting in **Error: Electron uninstall** even though the npm package exists. This was reproduced from the installed source. `scripts/ensure-electron.mjs` now checks the executable/version and invokes Electron's official installer when needed. Both `dev` and `preview` run this before electron-vite. The runtime was installed and its `--version` command returned `v44.3.0`.

The user asked to leave feature work as-is for now and fix development startup. Continue from that scope; do not restart feature expansion automatically.

## Firmware v4: alternating toggle freeze fixed

The user reported stalls when alternating Mute and Deafen. Whole-page state snapshots caused new RGB565 transfers for different toggle combinations. V4 preloads each toggle's OFF and ON image independently: OFF images are the base page, ALT transfers ON images once, STATE selects a per-key bitmask. Main-process successful actions send STATE directly; deviceReady stays true, and renderer runtime state changes no longer trigger page rendering/uploads. Firmware draws only changed cells (zero for an unchanged mask). Edited ON artwork marks its cell dirty so a same-state refresh still repaints. CRC failures preserve the prior alternate; allocations retain the PSRAM floor. Old snapshot allocations/alternates are freed when superseded.
