---
name: fusion-source-of-truth
type: constraint
---

The Fusion 360 design is the source of truth for every dimension. Always measure
in Fusion (via the Fusion MCP connection) rather than trusting numbers
remembered from a previous session or written in these notes.

Build notes also live inside the Fusion file itself, as component descriptions —
kept detailed and current for every part, including the reasoning behind each
tolerance, so they survive a lost chat.

**Why it matters:** numbers in chat and in notes go stale the moment a part is
edited; acting on a stale number means a wasted print. See [[fusion-file-split]].
