The project is open source, published as a public repository, and its name is
**Decky**. Do not rename it or propose alternatives. `streamdeck` survives only
as a legacy identifier: the Fusion file names and the `streamdeck 1` handshake
of the original touch-test firmware.

**Why it matters:** many names were rejected before this one was chosen, and
portmanteau or "slop"-sounding names are disliked. The name is settled.

See [[fusion-file-split]].
